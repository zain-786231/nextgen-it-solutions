# NextGen I.T Solutions — Website

Static Astro + Tailwind site for NextGen I.T Solutions, Arifwala, Pakistan.

```bash
npm install
npm run dev     # http://localhost:4321
npm run build   # → dist/
```

1. Fill in business details: `src/config/site.ts` (all `null` values are placeholders).
2. Deploy: [docs/CLOUDFLARE_DEPLOYMENT.md](docs/CLOUDFLARE_DEPLOYMENT.md)
3. SEO / Google setup: [docs/SEO_SETUP.md](docs/SEO_SETUP.md)
4. Updating products, software and images: [docs/CONTENT_UPDATE_GUIDE.md](docs/CONTENT_UPDATE_GUIDE.md)
5. Architecture & form behaviour: [docs/WEBSITE_GUIDE.md](docs/WEBSITE_GUIDE.md)
